# 方舟剧情白话版

用大白话重写《明日方舟》主线第0–8章（整合运动篇）和六篇重要支线（生于黑夜、覆潮之下、将进酒、叙拉古人、玛莉娅·临光、风雪过境）。不卖关子，人物关系一张图看清。

用浏览器打开 `index.html` 就能阅读，不用安装任何东西。

## 内容
- 世界观速览：源石、感染者、移动城市，以及原作憋着不说的几个关键前提
- 人物关系：可点击的关系图 + 按阵营分组的人物卡
- 主线第0–8章：每章一句话总结、白话故事、“这章你需要知道”
- 六篇重要支线
- 名词表

## 文件
```
index.html      页面框架
css/style.css   样式（支持深色模式和手机）
js/data.js      全部剧情文字与人物数据
js/app.js       路由、关系图交互
```

## 说明
非官方粉丝向导读。文字均为原创改写的梗概与解读，不收录游戏原文台词。剧情资料参考 PRTS 维基；《明日方舟》及相关角色版权归鹰角网络（Hypergryph）所有。
